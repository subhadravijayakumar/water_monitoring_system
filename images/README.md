# Project Images

Add genuine photographs of your assembled circuit and prototype to this folder after you have built them. Useful images include:

- A clear, top-down circuit photograph showing the Arduino, HC-SR04, LEDs, buzzer, resistors, and wiring.
- A photograph showing how the sensor is mounted above the tank.
- Optional photographs of the prototype at different water levels.

Do not add stock images or diagrams that could be mistaken for photographs of the tested prototype. Once you have real images, reference them from the root `README.md` using relative paths.
